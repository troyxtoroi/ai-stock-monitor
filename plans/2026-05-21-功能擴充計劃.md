# AI看盤小幫手 — 功能擴充計劃

**一句話目標：** 分四個階段為現有系統加入 Line 通知、操作日誌、AI 對話帶堂、回測功能，持續提升選股決策品質。

---

## 背景動機

現有系統已具備：
- GitHub Actions 每 5 分鐘自動抓取台股行情
- Python 計算 RSI / MACD / 布林通道等技術指標
- Claude API 產生買/賣/觀望訊號
- Netlify 靜態前端顯示 K 線圖與 AI 分析結果

**痛點**：訊號只能主動開網頁看，容易錯過；沒有記錄自己的操作；無法和 AI 討論自己的持股；策略好壞沒有數字驗證。

---

## 四個階段計劃

### Phase 1｜Line Notify 買賣訊號通知

**做什麼**
- 在 `scripts/fetch_all.py` 新增 `notify_line()` 函式
- 每次 AI 分析後，篩選出 `signal == "買入"` 或 `"賣出"` 的股票
- 透過 Line Notify API 推送訊息到使用者 Line

**產出**
- `scripts/notify.py`（或直接整合到 `fetch_all.py`）
- 在 GitHub Secrets 加入 `LINE_NOTIFY_TOKEN`
- `sync_stocks.yml` 傳入此環境變數

**訊息格式範例**
```
【AI看盤 訊號】 台積電 (2330.TW)
訊號：買入 ✅
信心：高
原因：RSI 28，跌破布林下軌（超賣），MACD 金叉
風險：整體市場仍偏弱
現價：886.0  漲跌：-1.2%
```

**注意**
- Line Notify 每日免費上限 1000 則，每 5 分鐘最多推一批，不會超量
- 訊號重複推送問題：記錄上次推送的訊號，相同訊號不重複送（可存 `data/last_signals.json`）

---

### Phase 2｜操作日誌（走師筆記）

**做什麼**
- 前端加入「新增操作紀錄」表單：股票代號、買/賣、價格、張數、日期、備註
- 操作紀錄存到 `data/trades.json`
- 頁面顯示操作歷史，並對照當時的 AI 訊號結果
- 計算每筆損益（對照今日收盤價）

**產出**
- `data/trades.json`
- 前端操作日誌 UI 區塊
- 統計區：總損益、勝率（賣出已實現）

**注意**
- 由於是靜態網站，操作紀錄需透過 localStorage 儲存在瀏覽器，或走 GitHub API 寫入 repo
- 建議先用 localStorage（簡單快速），之後可升級到 GitHub API

---

### Phase 3｜AI 自動帶堂 + 對話

**做什麼**
- 前端加入「我的持股」設定（股票代號 + 成本價）
- 加入聊天視窗，可輸入問題（如：「現在該加碼台積電嗎？」）
- 使用 Netlify Functions 建立後端 API，接收問題 → 整合持股資料 + 當前指標 → 呼叫 Claude API → 回傳回答

**產出**
- `netlify/functions/chat.js`（Netlify Function）
- 前端持股設定 UI + 聊天介面

**注意**
- Netlify Functions 免費額度 125,000 次/月，足夠個人使用
- Claude API 費用需管控：對話採用 claude-haiku（成本低），大型分析才用 sonnet

---

### Phase 4｜回測功能

**做什麼**
- 新增 `scripts/backtest.py`：讀取 `data/charts/` 歷史 K 線資料
- 模擬套用目前的規則訊號（RSI + MACD + 布林），計算：
  - 歷史買入/賣出點
  - 勝率（上漲/下跌方向對不對）
  - 平均報酬率
  - 最大回撤
- 結果輸出到 `data/backtest/` 供前端顯示

**產出**
- `scripts/backtest.py`
- `data/backtest/[symbol]_result.json`
- 前端回測結果頁面

**注意**
- 回測結果僅供參考，歷史績效不代表未來表現
- 先用日線資料回測（已有 6 個月資料）

## 預計成果

| 階段 | 完成後能做到 |
|------|------------|
| Phase 1 | 躺著收到買賣提醒，不再漏訊號 |
| Phase 2 | 所有操作有記錄，可以回顧每筆決策 |
| Phase 3 | 直接問 AI：「我現在持有 XX 張台積電，要加碼還是減碼？」|
| Phase 4 | 用數字驗證：這個策略過去 6 個月勝率是幾成 |

---

## 不包含範圍

- 自動下單（串接券商 API）
- 爬蟲台灣股市即時 Tick 資料（現在是 15 分鐘延遲）
- 多使用者 / 帳號系統

---

## 可能風險

| 風險 | 對策 |
|------|------|
| Line Notify 2025年底停止服務 | 可轉移到 Telegram Bot（架構類似） |
| Netlify Functions 冷啟動慢 | 快取分析結果，減少即時運算量 |
| GitHub Actions 抓資料超時 | 已有 try/except，逐一容錯 |
| yfinance 資料不穩 | 加入重試機制或備援資料源 |
